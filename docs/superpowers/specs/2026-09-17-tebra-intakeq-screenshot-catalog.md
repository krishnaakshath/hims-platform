# Tebra / IntakeQ Screenshot Catalog (Reference)

Extracted from a full read of 78 real screenshots (2 identical folder copies, so 78 unique screens) of Tebra and IntakeQ, both logged into practice "Inland Psychiatric Medical Group." No patient PHI is reproduced anywhere below — UI structure only. This file is a planning reference for later Clinsync phases; it does not itself specify what to build (see the phase specs/plans that cite it).

## Cross-cutting design patterns (both products)

- Teal/dark-teal global header, off-white body, white cards, thin borders.
- Status via colored pill/dot badges, never decorative icons alone.
- KPI dashboards: time-range pill selector + custom range at top, KPI card row, then stacked detail panels/charts.
- The "enterprise data-grid" toolbar (search, refresh, filter w/ badge count, column-settings gear, Export) plus per-column context menu (sort/pin/hide/manage columns) and a density picker is Tebra's most feature-rich list-view pattern (seen fully on Subscription Management) — a template for any Clinsync table that needs real power-user controls.
- Empty states: either a soft illustration + two-line message, or plain "No records found." text, depending on the screen's vintage — Clinsync should default to the plain-text version (matches the "no glass/illustration" design guidance already established for this product).
- IntakeQ favors nested folder hierarchies for organizing content (form templates); Tebra favors a left-sidebar accordion tree with saved/custom views (Reports module).
